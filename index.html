Os preços de referência vêm ao vivo da API oficial do Módulo Pesquisa de Preço (Compras.gov.br/Ministério da Gestão), consultada por código CATMAT/CATSER — nenhum valor é digitado por padrão. A opção de cotação manual serve apenas para registrar, com rastreabilidade, uma cotação real obtida por telefone, e-mail ou orçamento direto de fornecedor, como fonte adicional permitida pela IN SEGES/ME nº 65/2021. Este módulo roda inteiramente no navegador; se a chamada à API for bloqueada por CORS no domínio de publicação, ela deve ser roteada por um proxy (ex: Cloudflare Workers).
